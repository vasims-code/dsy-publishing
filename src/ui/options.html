From another server

Page metadata — ogTitle, the twitter handles, the page description — is always kept as it already is at the destination, because a locale's own wording cannot be derived from another one's. A page being created has nothing to keep, so it gets the source values as a starting point to edit.

Arabic flipping fixer

The lists the fixer's rules are built from: the units a number can carry — 256GB, 5000 mAh, 25°C — and the English feature names that stand on their own in Arabic copy. The rules themselves stay in the code. Clear a list to go back to the built-in one.

Broken Link Finder

Every CTA, link and image on a page is looked up on the author instance the page is on. A site-relative link — /sa_en/offers/ — is looked up under the content root, which the site root depth above decides: 3 means /content/samsung/sa_en/offers. Nothing is written, and the live site is never asked.

Product page templates

Pages made from these templates are product pages: their text comes from PIM, so the copy deck reads them as rendered, and their sheets cannot be imported. Give the full template path.

Copy deck fields

Fields added to the copy deck, or ignored, from its Fields not on the sheet list. A field is a component and a property — cm-g-promo-banner and cardTitle — and counts on every page that component is on. For the page's own properties the component is the page's. * means every component. Changes here apply at once; no Save needed.

Team defaults

Save my settings as team defaults downloads default-settings.json. Put it in the extension folder before zipping, and everyone who installs that zip starts with your settings. Settings they already have are never overwritten. Reset to team defaults puts every setting named in the file back, and replaces the copy deck field lists with the file's.
