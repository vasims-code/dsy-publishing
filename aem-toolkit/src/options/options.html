DSY - Digital Samsung Yard

Settings are stored in your Chrome profile and sync across your signed-in browsers.

Author instances

The extension only reads or writes on origins listed here, and Chrome asks for permission for each one. Removing an origin revokes that permission.

Features

Features that are hidden until you turn them on.

Lists every saved version of a page, read straight from the repository, and lets you restore one or create a new one with your own message.
Keeps a way back from a restore. Off by default, so a restore adds no version of its own.

Backup

Inserted directly under the site root to form every backup path: /content/samsung/levant/tvs is backed up to /content/samsung/levant/india/backup/tvs.
Used for inserted path segments that do not exist in the source.
How many leading path segments must already exist. 3 means /content/<brand>/<locale> is never created by the extension.

Page sync

Whether components removed at the source are removed at the destination is deliberately not here — it is a tick box on each run.

Comma separated. www.samsung.com is always included. A canonical pointing at a host that is not listed is reported but left alone.
Comma separated. These belong to the destination, not the source — hreflangGroup is the usual one.
Comma separated. A page copied from one of these sites shows two tick boxes on the review, under Image paths updated and Links updated: untick them to keep pointing at that site's images (nothing is uploaded) or at its links, instead of uploading and re-pointing them.

From another server

Page metadata — ogTitle, the twitter handles, the page description — is always kept as it already is here, because a locale's own wording cannot be derived from another one's. A page being created has nothing to keep, so it gets the source values as a starting point to edit.

Comma separated. Anything else this locale owns and maintains itself.

Copy deck fields

Fields added to the copy deck, or ignored, from its Fields not on the sheet list. A field is a component and a property — cm-g-promo-banner and cardTitle — and counts on every page that component is on. For the page's own properties the component is the page's, like page-standard-pd. * means every component. Changes here apply at once; no Save needed.

Team defaults

Share your setup: Save my settings as team defaults downloads default-settings.json. Put it in the extension folder before zipping, and everyone who installs that zip starts with your settings. Settings they already have are never overwritten; anything they add stays. Reset to team defaults puts every setting named in the file back, and replaces the copy deck field lists with the file's.
